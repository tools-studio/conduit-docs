| Button | Use for |
|---|---|
| Discord | General discussion, questions, and other Tools Studio users |
| Email | Direct support and general questions |
| Report an Issue | Bugs — see [Report Issues](report-issues.md) |
| Request a Feature | Feature ideas — see [Feature Requests](feature-requests.md) |

The Discord community is the general entry point for all Tools Studio tools, not Conduit-specific. It's the fastest way to ask a quick question or see how other users have set up their policies, but it isn't where bugs or feature requests are tracked — those go through GitHub Issues so they stay findable and don't get lost in chat history.
