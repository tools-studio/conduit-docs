# Community Links

| Link | Use for |
|---|---|
| [support.toolsstudio@gmail.com](mailto:support.toolsstudio@gmail.com) | Direct support, account or purchase questions |
| [Report an issue](https://github.com/toolsstudio/conduit-docs/issues) | Bugs — see [Report Issues](report-issues.md) |
| [Request a feature](https://github.com/toolsstudio/conduit-docs/issues) | Feature ideas — see [Feature Requests](feature-requests.md) |
| [Community](https://discord.gg/VrbxQ9vnrT) | General discussion, questions, and other Tools Studio users |

The Community Discord is the general entry point for all Tools Studio tools, not Conduit-specific. It's the fastest way to ask a quick question or see how other users have set up their policies, but it isn't where bugs or feature requests are tracked — those go through GitHub Issues so they stay findable and don't get lost in chat history.
