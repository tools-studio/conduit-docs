# Report Issues

Bug reports go to the [GitHub Issues](https://github.com/toolsstudio/conduit-docs/issues) tracker.

## Before opening an issue

Check [Troubleshooting](../docs/troubleshooting.md) and [FAQ](../docs/faq.md) — most common problems are answered there directly.

## What to include

- Conduit version (**About** tab, or `CHANGELOG.md` in the package)
- Unity version
- What you expected to happen, and what happened instead
- Steps to reproduce, if you have them
- The relevant Console output, if there's an error or warning

## Choosing a template

The tracker uses two issue templates:

- **Bug Report** — something isn't working as documented.
- **Feature Request** — something you'd like Conduit to do that it doesn't today. See [Feature Requests](feature-requests.md).

Picking the right template routes your issue to the right label automatically and helps it get triaged faster.

## Response time

Conduit is maintained by a small team. Expect an initial response within a few business days. Security-relevant issues — anything that could cause data loss or unexpected project modification — get priority; say so explicitly in the title.
