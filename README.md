# Conduit

Enforce asset import settings automatically across your Unity project. Define rules per folder, scan for settings drift, and reimport with correct settings applied in one click.

![Version](https://img.shields.io/badge/Version-1.0.0-24292f?style=flat-square)
![Unity](https://img.shields.io/badge/Unity-6000.3.10f1%20verified-24292f?style=flat-square)

Conduit is a paid, proprietary Unity Editor tool sold through the Unity Asset Store. This repository holds its user documentation. The Asset Store package includes the Conduit Runtime and Editor C# source, exactly as it ships in the product. The development GitHub repository that produces it is private.
